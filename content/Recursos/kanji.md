# Kanji
漢字


Literalmente significa carácter chino. Este sistema de escritura se usa para representar conceptos principalmente, aunque en ocasiones es usado su valor fonético.

Existen alrededor de 2000 caracteres considerados básicos, sin embargo, algunos periódicos requieren un conocimiento mínimo de 4000 caracteres para poder ser entendidos. 

La gran cantidad de caracteres, sumado a la diversidad de pronunciaciones que tiene cada uno, constituyen algunas de las principales complicaciones que se tienen a la hora de aprender el idioma japonés.
